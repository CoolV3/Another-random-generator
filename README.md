# Another Random Generator
A random name chooser.
An example use case would be if you play hide and seek with friends, and nobody wants to be seeker, you can use this to randomly select one.

## Features
Enter unlimited names and choose how many should get selected.
A cheat mode where you can choose who gets selected.


## Run it yourself
First install all dependencies
```bash
pnpm install
```
Then, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.


## Tech Stack
next.js framework
Lucide React for icons

Because my friends and I often play hide and seek and no one wants to be seeker.
